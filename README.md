# My Daily Tracker v2 (app + website, synced with Supabase)

1. Supabase: run supabase-setup.sql in the SQL Editor.
2. GitHub: upload everything in this folder (keep the hidden .github folder) to your repo.
3. APK: Actions -> "Build Android APK" -> Run workflow -> download the artifact.
4. Website: repo Settings -> Pages -> Source = "GitHub Actions", then run "Publish website".
   Your link will be https://YOUR-NAME.github.io/REPO-NAME/
The web app lives in www/index.html.
